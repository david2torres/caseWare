# Template updates client (Angular 21, Part 3)

Standalone components + signals, zoneless, no HTTP (in-memory fake gateway over fixtures).

```bash
npm install        # if npm reports a peer-dependency error: npm install --legacy-peer-deps
npm start          # http://localhost:4200
npm test -- --watch=false
```

Code lives in `src/app/template-updates/`:

| File | Role |
|---|---|
| `template-updates.contract.ts` | API contract types (same as DESIGN.md) |
| `template-updates.fixtures.ts` | Server-shaped fixture data; change items generated by the Java summary code |
| `template-updates.gateway.ts` | `TemplateUpdatesGateway` port + `FakeTemplateUpdatesGateway` |
| `template-updates.store.ts` | Signal store: list, selection, detail, decisions, polling, 409 handling |
| `template-updates-page.ts` | Route container, provides the store |
| `components/engagement-update-list.ts` | Presentational list |
| `components/pending-update-panel.ts` | Container for the selected engagement |
| `components/change-summary.ts` | Presentational summary (READY / COMPUTING / UNAVAILABLE) |
| `components/decision-actions.ts` | Apply / Decline with confirmation |

Demo scenarios: ENG-1007 and ENG-1003 (accumulated updates), ENG-1010 (summary computing, ready on next poll),
ENG-1011 (summary unavailable, decision blocked), ENG-1012 (not yet indexed).
